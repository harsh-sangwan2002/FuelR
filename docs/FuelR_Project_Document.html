01 · Overview
What is FuelR?

FuelR is a full-stack iOS application that combines AI-powered nutrition coaching with intuitive meal tracking. Users can log food by scanning photos, searching by name, or simply chatting with an AI coach — which understands natural language and takes actions on their behalf in real time.

The Problem

Nutrition tracking is tedious

Existing apps require manual searches through large databases, making daily logging feel like a chore that most users abandon within a week.

The Solution

Conversational + visual logging

FuelR lets users say "log 200g chicken to lunch" or snap a photo of their meal — the AI handles estimation, logging, and feedback instantly.

Key Highlights
  • AI nutrition coach with agentic tool-use loop powered by Claude Opus 4.8
  • Date-aware dashboard — view and edit any day's nutrition log
  • Food photo analysis via Claude's vision capabilities
  • Per-meal breakdown: Breakfast, Lunch, Dinner, Snacks
  • Real-time macro tracking: calories, protein, carbs, fat
  • Water intake tracking integrated into AI conversation
  • Persistent chat history with Firestore session storage
  • Firebase Authentication for secure user accounts

03 · AI Integration
Agentic AI System
Claude Opus 4.8 Adaptive Thinking Tool Use Loop

How the AI Agent Works

The nutrition AI is built as a custom agentic loop using raw fetch calls to the Anthropic API (the Node SDK is not used — it imports node:fs which crashes React Native's Metro bundler). The agent runs up to 6 iterations per turn, with thinking blocks preserved across the conversation history. Every tool call targets the date selected on the dashboard — past, today, or future.

get_today_nutrition
Fetch full log for the target date
log_food_item
Add food to a meal on any date
update_water_intake
Set water glass count for a date
estimate_food_nutrition
Estimate macros for any food name
analyze_food_image
Vision analysis of a food photo
get_nutrition_goals
Read the user's calorie/macro goals
Date Synchronisation

When the user selects a date on the Nutrition Home screen, that date propagates as a targetDate parameter through every navigation action. The AI chat screen reads this parameter, passes it to the agent, and the system prompt explicitly tells Claude which date it is operating on — preventing any confusion between today and historical dates.
